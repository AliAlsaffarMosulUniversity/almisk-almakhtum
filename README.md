# المسك المختوم

نافذة واحدة على المحتوى الإسلامي في يوتيوب.

**الرابط:** https://alialsaffarmosuluniversity.github.io/almisk-almakhtum/

- 20 قسماً بأزرار ملونة: القرآن الكريم، التجويد، التفسير، الحديث، الخطب، الدعوة إلى الله، السيرة، الفقه، العقيدة، الأذكار، ركن الأطفال، وغيرها.
- قسم القرآن: 36 قارئاً مع اختيار أي سورة من 114 سورة.
- تصفية النتائج: قوائم تشغيل، مقاطع طويلة، الأحدث، بث مباشر، قنوات.
- مفضلة تُحفظ على الجهاز، ومظهر داكن وفاتح.
- يُثبَّت على الهاتف كتطبيق (PWA).

التطبيق لا يستضيف أي محتوى. كل زر يفتح نتائج يوتيوب مباشرة.

تصميم: علي الصفار
